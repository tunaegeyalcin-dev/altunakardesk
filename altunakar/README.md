# AltunakarDesk

AltunakarDesk, Altunakar Bilgisayar'ın uzak masaüstü programıdır. Açık kaynak
[RustDesk](https://github.com/rustdesk/rustdesk) projesine dayanır; RustDesk
© Purslane Tech Pte. Ltd. Bu çatal da aynı lisansla (GNU AGPL-3.0) yayınlanır;
değiştirilmiş kaynak kodun tamamı bu depodadır.

AltunakarDesk is Altunakar Bilgisayar's remote desktop application, based on the
open source RustDesk project (© Purslane Tech Pte. Ltd.) and released under
GNU AGPL-3.0. The complete modified source is in this repository.

## Gizlilik
Bağlantılar Altunakar'ın kendi merkezi `desk.tunayalcin.blog` üzerinden kurulur.
Ekran, ses ve dosyalar iki bilgisayar arasında uçtan uca şifrelidir; merkez
içeriği göremez. Program RustDesk'in sunucularına bağlanmaz.

## Linux
Wayland oturumlarında ekran paylaşımı için X11 oturumu önerilir.
